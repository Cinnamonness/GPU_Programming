## Формулировка задания по Лабораторной работе 3 
 
Реализовать программу для накладывания фильтров на изображения. Возможные фильтры: размытие, выделение границ, избавление от шума. Изменить время
Для работы с графическими файлами рекомендуется использовать libpng (man libpng). Примеры использования библиотеки в /usr/share/doc/libpng12-dev/examples/
Считать изображение из файла, преобразовать в массив, отправить на CUDA Device, провести на устройстве обработку фильтром, вернуть изображение в память хоста, преобразовать в картинку, сохранить файл.

Для выполнения использовать две видеокарты.

## Реализация

Программа реализована для параллельной обработки изображений на двух графических процессорах. Основная цель - ускорение применения фильтров к изображениям за счет распределения вычислений между несколькими GPU.

### Основные компоненты программы

1. Структуры данных для хранения изображений и управления GPU

2. CUDA ядра для параллельной обработки пикселей

3. Функции ввода-вывода для работы с PNG форматом

4. Система управления двумя GPU для распределения вычислений

### Структуры данных

#### Структура Image

``` C
struct Image {
    int width;
    int height;
    unsigned char *data;
};
```
Хранит информацию об изображении: ширину, высоту и указатель на данные в формате RGBA (4 байта на пиксель).

#### Структура DualGPUContext

``` C
struct DualGPUContext {
    int gpu0;
    int gpu1;
    size_t total_size;
    size_t split_height;
};
```

* gpu0 и gpu1 - идентификаторы используемых gpu

* split_height - высота разделения изображения между GPU

### Инициализация системы двух GPU

Функция initDualGPU() выполняет настройку двух-GPU окружения:

``` C
DualGPUContext initDualGPU(int image_height) {
    DualGPUContext context;
    
    // Проверка доступности GPU
    int device_count;
    cudaGetDeviceCount(&device_count);
    
    if (device_count < 2) {
        fprintf(stderr, "Error: Need at least 2 GPUs, but only %d found\n", device_count);
        exit(1);
    }
    
    context.gpu0 = 0;
    context.gpu1 = 1;
    
    // Разделение изображения по горизонтали
    context.split_height = image_height / 2;
    
    return context;
}
```

### CUDA ядра для обработки изображений

#### Ядро сильного размытия (5x5 гауссов фильтр)

``` C
__global__ void strongBlurKernel(unsigned char* input, unsigned char* output, 
                               int width, int height, int start_y) {
    int x = blockIdx.x * blockDim.x + threadIdx.x;
    int y = blockIdx.y * blockDim.y + threadIdx.y;
    int global_y = y + start_y;
    
    if (x >= width || global_y >= height) return;
    
    // Матрица свертки 5x5
    float kernel[5][5] = {
        {1/256.0f, 4/256.0f,  6/256.0f,  4/256.0f, 1/256.0f},
        {4/256.0f, 16/256.0f, 24/256.0f, 16/256.0f, 4/256.0f},
        {6/256.0f, 24/256.0f, 36/256.0f, 24/256.0f, 6/256.0f},
        {4/256.0f, 16/256.0f, 24/256.0f, 16/256.0f, 4/256.0f},
        {1/256.0f, 4/256.0f,  6/256.0f,  4/256.0f, 1/256.0f}
    };
    
    // Применение свертки
    for(int ky = -2; ky <= 2; ky++) {
        for(int kx = -2; kx <= 2; kx++) {
            // Обработка границ изображения
            int nx = min(max(x + kx, 0), width - 1);
            int ny = min(max(global_y + ky, 0), height - 1);
            // ... вычисления для каждого канала
        }
    }
}
```

### Система распределения вычислений между GPU

#### Алгоритм распределения

1. Инициализация контекста двух GPU

2. Разделение изображения на две части по горизонтали

3. Распределение по GPU:

    * GPU 0 обрабатывает верхнюю часть (0 : split_height)

    * GPU 1 обрабатывает нижнюю часть (split_height : height)

4. Оба GPU работают одновременно - параллельное выполнение

5. Сбор и объединение результатов

#### Настройка сетки и блоков

``` C
// Размер блока: 32×8 потоков (256 потоков на блок)
dim3 blockDim(32, 8);

// Расчет размеров сетки
int gridX = (input.width + blockDim.x - 1) / blockDim.x;
int gridY1 = (context.split_height + blockDim.y - 1) / blockDim.y;
int gridY2 = ((input.height - context.split_height) + blockDim.y - 1) / blockDim.y;
```

* Ширина изображения: 2000 пикселей

* Высота изображения: 2000 пикселей

* Разделение: по 1000 строк на каждый GPU

* Блоки: 32×8 = 256 потоков

* Сетка GPU0: 63×125 блоков

* Сетка GPU1: 63×125 блоков

#### Управление памятью и выполнение

``` C
// Выделение памяти на GPU 0
cudaSetDevice(context.gpu0);
cudaMalloc(&d_input0, total_size);
cudaMalloc(&d_output0, total_size);
cudaMemcpy(d_input0, input.data, total_size, cudaMemcpyHostToDevice);

// Выделение памяти на GPU 1  
cudaSetDevice(context.gpu1);
cudaMalloc(&d_input1, total_size);
cudaMalloc(&d_output1, total_size);
cudaMemcpy(d_input1, input.data, total_size, cudaMemcpyHostToDevice);

// Запуск ядер на обоих GPU
cudaSetDevice(context.gpu0);
blurKernel<<<gridDim0, blockDim>>>(d_input0, d_output0, input.width, input.height, 0);

cudaSetDevice(context.gpu1);
blurKernel<<<gridDim1, blockDim>>>(d_input1, d_output1, input.width, input.height, context.split_height);
```

#### Обработка граничных условий

В ядрах реализована обработка границ изображения: 

``` C
int nx = min(max(x + kx, 0), width - 1);   // Ограничение по X
int ny = min(max(global_y + ky, 0), height - 1);  // Ограничение по Y
```

#### Обработка ошибок и синхронизация

Программа включает механизмы обработки ошибок:

``` C
// Проверка ошибок CUDA после запуска ядер
cudaError_t err;
cudaSetDevice(context.gpu0);
err = cudaGetLastError();
if (err != cudaSuccess) {
    fprintf(stderr, "GPU0 Kernel error: %s\n", cudaGetErrorString(err));
}
```

Синхронизация обоих устройств гарантирует завершение всех вычислений перед сбором результатов:

``` C
cudaSetDevice(context.gpu0);
cudaDeviceSynchronize();
cudaSetDevice(context.gpu1); 
cudaDeviceSynchronize();
```
