### Пояснения к полученным параметрам

- Device has Compute Capability — вычислительная способность GPU, определяет поколение архитектуры (важно при выборе версии CUDA и совместимости).

- Device name - название видеокарты.

- Total global memory - объём глобальной памяти GPU.

- Shared memory per block - объём разделяемой памяти, доступной на один блок потоков.

- Registers per block - количество регистров, доступных на блок.

- Warp size - размер варпа (группы потоков, исполняемых одновременно).

- Max threads per block - максимальное число потоков в одном блоке.

- Max threads dimensions - допустимые размеры блока по осям X, Y, Z.

- Max grid size - максимальные размеры сетки блоков.

- Clock rate - тактовая частота ядра.

- Total constant memory - объём постоянной памяти.

- Compute capability - вычислительная способность GPU.

- Texture alignment - выравнивание текстур в памяти.

- Device overlap - поддержка перекрытия вычислений и копирования данных.

- Multiprocessor count - количество мультипроцессоров (SM) на устройстве.

- Kernel execution timeout enabled - наличие ограничения времени выполнения ядер.

## Параллельное создание матрицы на GPU

Программа демонстрирует сравнение производительности CPU и GPU при создании большой квадратной матрицы размером 5000 * 5000 элементов.

Каждый элемент вычисляется по формуле: A[i][j]=10 * i * j

* CUDA ядро `createMatrix` - параллельное создание матрицы на GPU

* CPU функция `createMatrixCPU` - последовательное создание матрицы на CPU

* Система измерения времени с использованием событий CUDA

* Проверка корректности результатов вычислений

## Транспонирование матрицы на GPU

Программа реализует параллельное транспонирование матрицы на GPU с использованием CUDA и сравнивает производительность с CPU-версией.

---
### Ключевые компоненты кода

**Ядро CUDA** - параллельно копирует элементы матрицы A в транспонированное расположение AT. Каждый поток обрабатывает один элемент.

``` C
__global__ void matrixTranspose(const BASE_TYPE *A, BASE_TYPE *AT, int rows, int cols)
{
    int iA = cols * (blockDim.y * blockIdx.y + threadIdx.y)
           + blockDim.x * blockIdx.x + threadIdx.x;
    int iAT = rows * (blockDim.x * blockIdx.x + threadIdx.x)
            + blockDim.y * blockIdx.y + threadIdx.y;
    AT[iAT] = A[iA];
}
```

**Функция CPU-версии** - последовательное транспонирование для сравнения производительности и проверки корректности результата GPU.

``` C
void matrixTransposeCPU(const BASE_TYPE *A, BASE_TYPE *AT, int rows, int cols)
{
    for (int i = 0; i < rows; i++)
        for (int j = 0; j < cols; j++)
            AT[j * rows + i] = A[i * cols + j];
}
```

**Выравнивание размеров** - выравнивание размеров

Обеспечивает кратность размеров блока BLOCK_SIZE (для оптимального распределения потоков).

``` C
int toMultiple(int a, int b)
```

## Умножение матриц


Программа реализует умножение двух матриц (A и B) на CPU и GPU с использованием CUDA, измеряет время выполнения и сравнивает производительность. Она также проверяет корректность вычислений и анализирует расходы на передачу данных.

**Используемые типы и размеры**

* BASE_TYPE: float - тип элементов матриц

* BLOCK_SIZE: 16 - размер блока CUDA (16×16 потоков на блок)

* Матрицы:

    * A: 500×400

    * B: 400×300

    * C = A × B: 500×300

Для оптимальной работы CUDA размеры матриц выравниваются до кратного размера блока, с помощью функции `toMultiple`.

**Выделение и инициализация памяти**

*1. На CPU (хост)*

    *  h_A, h_B, h_C_cpu, h_C_gpu - массивы в памяти хоста

    * h_A и h_B инициализируются случайными числами в диапазоне [0,1]

*2. На GPU (устройство)*

    * d_A, d_B, d_C - массивы в глобальной памяти GPU, выделяются с помощью cudaMalloc. 

    * Данные копируются с CPU на GPU через cudaMemcpy


**Умножение матриц**

*1. На CPU*

``` C
for (i=0; i<Arows; i++)
  for (j=0; j<Bcols; j++)
    for (k=0; k<Acols; k++)
      C[i*Bcols+j] += A[i*Acols+k] * B[k*Bcols+j];
```

*2. На GPU*

Используется ядро `matrixMult`

``` C
int row = blockDim.y*blockIdx.y + threadIdx.y;
int col = blockDim.x*blockIdx.x + threadIdx.x;
if (row < Arows && col < Bcols)
  for (int k=0; k<Acols; k++)
    C[row*Bcols+col] += A[row*Acols+k]*B[k*Bcols+col];
```

* threadIdx — индекс потока внутри блока

* blockIdx — индекс блока в сетке

* blockDim — размеры блока

Каждый поток вычисляет один элемент результирующей матрицы C. Потоки сгруппированы в блоки размером 16×16

**Размер сетки**

``` C
dim3 threadsPerBlock(BLOCK_SIZE, BLOCK_SIZE);
dim3 blocksPerGrid((Bcols+BLOCK_SIZE-1)/BLOCK_SIZE, (Arows+BLOCK_SIZE-1)/BLOCK_SIZE);
```

* Количество потоков на блок: 16×16 = 256

* Количество блоков в сетке:

    * по строкам: ceil(Arows / BLOCK_SIZE)

    * по столбцам: ceil(Bcols / BLOCK_SIZE)

* Всего потоков: число блоков × число потоков в блоке


**Итерации**

1. Ядро запускается 100 раз для более точного измерения производительности

2. Среднее время одной итерации вычисляется как общее время ядра / 100

**Замер времени**

Используются события CUDA (cudaEvent_t) для точного измерения

1. start_total / stop_total — общее время программы

2. start_cpu / stop_cpu — время выполнения на CPU

3. start_mem / stop_mem — время выделения памяти и копирования данных на GPU

4. start_kernel / stop_kernel — время выполнения ядра GPU

5. Копирование результата обратно на CPU также замеряется отдельным событием


*Время работы делится на*

1. Работа с памятью (копирование CPU ↔ GPU)

2. Вычисление ядра (GPU)

3. Прочие накладные расходы (инициализация, вызовы функций CUDA)

**Проверка корректности**

* Сравниваются 100 случайных элементов C GPU и C CPU

* Программа выводит пример первых 2×2 элементов A, B и C

* Ошибка считается критической, если разница > 1e-3
